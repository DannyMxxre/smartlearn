# ИИ-наставник (хакатон Столото)

## Цель
ИИ-наставник, который в коротком разговоре оценивает уровень владения ИИ-инструментами у сотрудника ИТ и выдаёт персональный план развития.

## Роли
- Аналитик (системный / бизнес-аналитик)
- Разработчик (backend / full-stack)

## Обязательный поток
1. Знакомство — выбор роли, цель, текущие навыки
2. Диагностика — задания под роль (тесты + практика)
3. Отчёт — уровень, сильные стороны, что подтянуть
4. План — конкретные шаги на месяц

## Киллер-фичи
1. Генерация структурированного Roadmap по результатам диагностики
2. Поиск платных и бесплатных курсов и прикрепление их к Roadmap (готовый план обучения)
3. AI-тренажёр — практические задания по выявленным пробелам

## Архитектура
- Backend: Java + Spring Boot
- Frontend: React + Vite
- LLM: GigaChat (Gigachat, OpenAI-совместимый API)
- Сессии: in-memory (ConcurrentHashMap)
- Данные: только выдуманные

## Приоритеты
1. Сначала рабочий сквозной сценарий (4 шага) + честная оценка (сильные/слабые ответы дают разный уровень)
2. Потом Roadmap + поиск курсов
3. Потом AI-тренажёр
4. README + схема архитектуры

## Стек
- Spring Boot 3
- RestClient / WebClient для GIgachat
- React + Vite
