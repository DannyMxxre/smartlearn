Бэкенд
Проект backend на Spring Boot 4.1.1, Java 25, Maven. Сборка с JAVA_HOME на Temurin 25.

Один диалог, одна сессия в памяти (ConcurrentHashMap). После перезапуска сервера сессии пропадут — для хакатона этого достаточно.

POST /api/chat принимает sessionId и текст. В ответе: реплика наставника, фаза, номер вопроса и, в конце, структурированный отчёт.

Фазы такие:

Знакомство. Роль (аналитик или разработчик), цель на месяц, как человек уже пользуется ИИ.
Диагностика. 4 задания под выбранную роль: как ставит задачу модели, как проверяет результат, практический промпт и где ИИ лучше не использовать.
Отчёт и план. Уровень, баллы, сильные стороны, пробелы и шаги на 4 недели. Это один ответ в конце, чтобы не делать лишних вызовов модели.
Роль и переходы между фазами задаёт код, не модель. Иначе диалог легко уезжает в свободный разговор и сценарий ломается.

Оценка
Каждый ответ получает 0–3 балла по рубрике. Уровень считается суммой в коде:

Сумма из 12	Уровень
0–3
Новичок
4–6
Базовый
7–9
Уверенный
10–12
Продвинутый
Модель пишет обоснования, сильные стороны и план. Уровень она не назначает. Температура низкая, чтобы повтор с теми же ответами давал близкий результат. Если ключа YandexGPT нет, временно считает запасной разборщик по тексту ответа, чтобы интерфейс можно было проверить без облака.

YandexGPT
RestClient на OpenAI-совместимый адрес https://ai.api.cloud.yandex.net/v1. Ключ, folder id и модель берутся из переменных окружения, в репозиторий не попадают. Модель вызывается один раз, в конце диагностики.

Фронт
React + Vite: лента сообщений, поле ввода и индикатор фазы. В конце отдельно карточка отчёта: уровень, баллы, сильные стороны, пробелы, план по неделям. Запросы идут на localhost:8080.
